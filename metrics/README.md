# Metrics

`history.jsonl`: one JSON object per audit run, e.g.

{"date":"2026-10-20","open_p0":0,"open_p1":2,"open_p2":5,"axe_serious_critical":51,"pages_with_overflow":0,"pages_with_console_errors":2,"verified_obligations":12,"readiness_score":2.1}

`readiness.md`: the SaaS-readiness scorecard (see `STRATEGY.md`), refreshed
monthly by the auditor with dated evidence per dimension.
