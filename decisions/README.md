# Decision briefs

For choices only the owner should make (backend vendor, pricing, who to
approach, scope of a new tool). An agent writes one short brief per
decision; the owner decides in one tap on a phone.

- File: `NNN-short-name.md` (see `TEMPLATE.md`), opened as a PR titled
  `Decision: ...` from an `audit/<date>` branch.
- **Merging the PR accepts the recommended option. Closing it defers.**
  To choose another option, comment its letter on the PR; the next agent
  run records it and implements accordingly.
- Agents never act on a decision before it is merged or answered.
