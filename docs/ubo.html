UBO Discovery

Reconstructs corporate ownership from filings, calculates indirect holdings at any depth, and shows which individuals qualify as beneficial owners — with every percentage traced to the sentence that states it.
How this works
Your documents are read in this browser tab and go no further. This site has no server that could receive them. The analysis is done by Ollama running on your own machine — install it once, and the upload box above starts working.

Drop PDFs above to build an ownership graph: indirect holdings at any depth, circular structures, and every percentage traced to the sentence that states it.

Or, if a colleague sent you a finished analysis:

  1. Open a result file with Load investigation… — read in this tab, never uploaded.
  2. Try the mechanics with the worked example, which uses invented data.
The worked example uses an invented company and invented documents. It exists to show the mechanics — nothing in it is real.
One-time setup
  1. Install Ollama — ollama.com/download
    Runs the AI model on your machine. Free.
  2. Get the model
    ollama pull llama3.1:8b
    ~5 GB, once. Then it works offline.
  3. Allow this site to reach Ollama
    launchctl setenv OLLAMA_ORIGINS "*"
    Then restart Ollama. Needed once — Ollama blocks websites by default.
Why install anything at all?
Because the alternative is sending your documents to someone's server. The model runs on your machine, so the files never leave it — and you can prove that by turning off the wifi and watching the analysis still work.

What this page does

It displays an ownership analysis: the graph, the indirect-ownership arithmetic, the evidence behind each percentage. It does not analyse documents — that runs on your own machine, offline. This page has no backend and no database.

What it is not
  • Not a UBO determination. It assembles evidence and shows the arithmetic; the conclusion is the analyst's.
  • Not a system of record. Nothing is stored — close the tab and it is gone.
  • Not validated. It is a prototype built in evenings, with none of the review a production compliance system requires.
A word on the extraction

Every fact must carry a quotation found verbatim in the source document; anything else is discarded rather than flagged. The tool therefore misses relationships more often than it invents them — which is the right direction to fail, but means you must read the graph against the documents rather than trusting it.
