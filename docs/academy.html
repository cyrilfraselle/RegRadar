HOW IT'S DIFFERENT

Not slides. A desk.

Everything else teaches AML by describing it. This puts you in front of an inbox that gets mail, a browser with a real customer file open in it, and a queue that doesn't wait for you to finish reading.
🖥️

A real environment

Draggable windows, a taskbar, an inbox, a Chrome-style browser with the customer profile and company registry open in tabs, a File Explorer with the actual KYC folder. You navigate it, nobody hands you the answer on a slide.

💬

A mentor, not a manual

Alex — senior on the desk — reacts to what you actually do: a catch, a wrong call, a file that comes back to bite you. He talks more when you're new, and steadily less as you rank up. That's the point.

🔒

A path, not a menu

Laundromat, then Ownership, then the Desk — locked in that order, because you can't recognise a pattern you've never produced. Each module opens once the one before it is done.

THE PATH

Three modules, in the order the job teaches them.
