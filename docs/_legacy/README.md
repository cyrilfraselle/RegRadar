# _legacy

Pages that used to be live, kept for reference and not linked from the
site's navigation. Nothing here is loaded by any current page.

## feed.html

The original dashboard-style regulatory feed. Superseded by
[`regwatch.html`](../regwatch.html), which replaced it as the target of
`docs/index.html` — a profile-driven workspace instead of a flat feed,
built on the same `docs/data/items.json` / `meta.json`. Archived here
rather than deleted so the earlier design stays reachable if needed.
